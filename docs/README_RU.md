# Audion PPTX Print to PDF Tool

[English](README_EN.md) · [Руководство](USER_GUIDE_RU.md)

Пакетная печать презентаций через системный принтер «Microsoft Print to PDF» с
последующей обрезкой под нужный формат.

## Зачем это сделано

Экспорт презентации в PDF и печать её в PDF — **разные вещи**, и результат
отличается. Печать проходит через драйвер принтера: применяются настройки
страницы, поля, масштабирование. Иногда нужен именно этот путь — например, когда
принимающая сторона ждёт документ, прошедший через печать.

Пакетной печати PowerPoint не умеет. Программа умеет.

## Порядок работы

1. Сделать «Microsoft Print to PDF» принтером по умолчанию.
2. Положить презентации во входную папку.
3. Запустить печать.
4. Обрезать полученное под `16:9` или A4/A3.

Обрезка идёт отдельно от печати: печать даёт страницу как есть, а подгонка под
формат делается по готовому PDF.

## Техническая часть

### Требования

Установленный PowerPoint и системный принтер «Microsoft Print to PDF», выбранный
по умолчанию. Программа не переключает принтер за вас: это системная настройка, и
менять её молча она не должна.

### Форматы

Принимаются `.pptx` и `.pptm`.
